# Persian trainer — agent notes

```
kaikki (Wiktionary fa) ──┐
Tatoeba pes/eng ─────────┼─> tools/build_pack.py (packbuilder, langs/fa.py)
FrequencyWords + wordfreq┘        │
Stanza (fa Seraji, build-time only)│  gloss_overrides.json, forced_a1.txt,
                                    │  generated_sentences.tsv, passages_src.json,
                                    │  id_map_v1.json
                                    v
                          pack/*.json --jsonify_pack.py--> pack/*.js
                                    │
     ezafe_say.py (Stanza depparse) --> tools/audio_say.json (spoken-text overrides)
     packbuilder audio --lang fa      --> audio/{w,s,p,x}/*.opus + audio/manifest.json
                                    v
              build.sh (engine/build.sh: engine/app.html + engine/core.js + pack js)
                                    v
                    index.html + sw.js -> GitHub Pages
                    https://bannerless-studio.github.io/persian/
progress lives in localStorage key vocab_fa on the shared origin
```

Why it is built this way: single-file site + service worker for offline; engine as a
git submodule so every language ships the same drills; pack ids frozen
(`tools/id_map_v1.json`) so learner progress survives rebuilds. Persian ships recorded
Piper (`ganji_adabi`) audio for every word, sentence, passage sentence and script unit
because there is no permissively licensed Persian audio to license and no reliable
Persian TTS voice on every device (see README.md "Script primer"). Recording needs the
ezafe (unwritten in Persian text) spelled out, which `tools/ezafe_say.py` derives from
a dependency parse before the shared `packbuilder audio` step synthesizes it.

## Commands (pinned)

- Rebuild pack: `python3 tools/build_pack.py` (equivalent to
  `PYTHONPATH=engine/tools python3 -m packbuilder build --lang fa --repo .`), then
  `python3 engine/tools/jsonify_pack.py pack`
- Rebuild reading passages: `PYTHONPATH=engine/tools python3 -m packbuilder passages --lang fa .`
  then `python3 engine/tools/jsonify_pack.py pack`
- Ezafe overrides (before any audio rebuild that touches sentences/passages):
  `.venv/bin/python tools/ezafe_say.py [--sample N]` (writes `tools/audio_say.json`)
- Rebuild audio: `python3 -m packbuilder audio --lang fa --repo . [--check] [--prune] [--only w,s,p,x] [--limit N]`
  (see `engine/docs/AUDIO.md`)
- Build site: `./build.sh`
- Check (must pass before every commit of index.html): `./check.sh`
- Against a non-submodule vocab-engine checkout: set
  `PACKBUILDER_PATH=../vocab-engine/tools` for both `tools/build_pack.py` and `./check.sh`
- Engine tests live in vocab-engine (see its CLAUDE.md)

## Always

- Commit index.html and sw.js together; check.sh's stale-build guard runs post-commit.
- Bump the engine submodule only to a vocab-engine main sha; rebuild after every bump.
- Keep ids append-only; never renumber (`tools/id_map_v1.json`).
- Re-run `tools/ezafe_say.py` before rebuilding audio whenever sentence or passage text
  changed, so spoken text stays in sync with pack text.
- Path-limited commits: engine, index.html, sw.js, pack/, tools/, audio/, README.md,
  TODO.md; never .venv or .cache.

## Never

- Edit pack/*.json by hand; change tools/gloss_overrides.json, tools/forced_a1.txt or
  tools/generated_sentences.tsv and rebuild instead.
- Edit pack/*.js, index.html or sw.js by hand (generated).
- Edit audio/*.opus or audio/manifest.json by hand (generated by `packbuilder audio`).
- Delete sw.js (use engine/sw.disable.js).
- Add comments that say what the code does; only why, or an external reference.
- Push to main without `git merge-base --is-ancestor origin/main HEAD`.

## Generated files

pack/*.js, pack/*.json, index.html, sw.js, tools/REPORT.md, tools/REPORT_passages.md,
tools/id_map_v1.json (frozen, hand-edit never), tools/audio_say.json (regenerate with
ezafe_say.py, don't hand-edit), audio/*.opus + audio/manifest.json (regenerate with
`packbuilder audio`).

## Where things are

README.md (end users), tools/README.md (builder inputs, file by file, incl. the audio
pipeline), TODO.md (residuals + QA history), engine/ (submodule, read-only here),
engine/docs/AUDIO.md (shared audio-pipeline reference).
